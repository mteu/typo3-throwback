# TYPO3 3.3.0 in your browser

TYPO3 3.3.0, released 2002-06-03, is the oldest publicly available TYPO3. In
your browser, it runs on PHP 4.4.9, compiled to WebAssembly.

[Open TYPO3 3.3.0](../../3.3/){ .md-button .md-button--primary }

| What | Where | Credentials |
| --- | --- | --- |
| Frontend | the site's own page | none |
| Backend | `typo3/` | `admin` / `password` |
| Install Tool | `typo3/install/` | `joh316` |

The site starts as the Docker stack does: an admin, a root page, and the
"GREEN" template that shipped with 3.3.0.

## What is different from the Docker stack

- **The clock starts at 2002-06-03 12:00 UTC,** and runs from there.
- **The menus are drawn by GD.** GREEN draws its menu titles with ImageMagick,
  which cannot run in a page. The site turns that option off, as a 2002
  server without ImageMagick would have, and GD draws plain text instead.
- **The Install Tool skips its ImageMagick tests,** and says why. Its own GD
  tests match the reference images 3.3.0 ships, except TrueType text: today's
  FreeType draws slightly different pixels than 2002's.
- **TYPO3 moves files with PHP, not with `mv`.** 3.3.0 has that setting for
  Windows servers. Here, no program can be started at all.
