# TYPO3 4.5.40 in your browser

TYPO3 4.5.40, released 2015-02-19, is the last release of the first LTS. In
your browser, it runs on PHP 5.6.40, compiled to WebAssembly.

[Open TYPO3 4.5.40](../../4.5/){ .md-button .md-button--primary }

| What | Where | Credentials |
| --- | --- | --- |
| Frontend | the site's own page | none |
| Backend | `typo3/` | `admin` / `password` |
| Install Tool | `typo3/install/` | `joh316` |

The site starts as the Docker stack does: an admin, a root page, and a plain
TypoScript template that names the release and the PHP it runs on. The root
page's title is "Skaarhøj · Gödöllő · 日本語", stored as UTF-8, as 4.5 stores
everything. The frontend shows it, read back from the database.

The backend is 4.5's own: one ExtJS page with the module menu, the page tree
and each module beside them. The page tree loads over Ext.Direct, as raw JSON
requests, which reach PHP as they do in Docker.

## What is different from the Docker stack

- **PHP 5.6.40, as in Docker, but with fewer extensions.** The Docker stack
  runs the official PHP 5.6 image, with gd, mysql and soap added. In your
  browser, PHP has what 4.5.40 uses: the extensions its Install Tool asks
  for (filter, gd, json, mysql, pcre, session, SPL, standard, xml and
  zlib), the ones its core calls (ctype, hash, Reflection and tokenizer),
  dom, SimpleXML, libxml, XMLReader, fileinfo, OpenSSL and SOAP. Its random
  bytes come from OpenSSL, as in Docker. The same PHP serves 6.2.31, so it
  also has mysqli and zip, which 4.5.40 does not use. It lacks mbstring,
  iconv, cURL, PDO, SQLite3, Phar and the official image's other
  extensions. 4.5.40 does without them by default: it converts charsets
  with its own tables.
- **The same `php.ini`.** The site uses the Docker stack's own settings,
  `always_populate_raw_post_data = -1` included, so the page tree's raw
  JSON requests get no deprecation notice in their answers.
- **The clock starts at 2015-02-19 12:00 UTC,** and runs from there.
- **Images are drawn by GD.** ImageMagick cannot run in a page, so the site
  turns it off, as a 2015 server without it would have. 4.5.40 then limits
  images to GIF, JPEG and PNG itself.
- **The Install Tool skips its ImageMagick tests,** and says why. Its own GD
  tests match the reference images 4.5.40 ships, except TrueType text:
  today's FreeType draws slightly different pixels than 2015's.
- **TYPO3 moves files with PHP, not with `mv`.** 4.5.40 has that setting for
  Windows servers. Here, PHP can start one program only: `/bin/true`. The
  Docker stack sends mail to it, so mail is "sent" and goes nowhere, here as
  there. The Install Tool's test mail goes through 4.5's own mailer, as in
  Docker.
- **The database answers as MySQL 5.5.62, in UTF-8,** the server and the
  character set the Docker stack runs. It counts, compares and sorts text as
  MySQL's `utf8_general_ci` does: `varchar(n)` keeps n characters, and
  "Gödöllő" equals "GODOLLO". It answers `SET NAMES`, the character set and
  `sql_mode` variables, `information_schema`, and the `SHOW` statements 4.5
  sends. Everything else answers as for the older releases. TYPO3 sends the
  same statements to it, and every one of them works.
- **The trusted hosts pattern is open, as in Docker.** By default, 4.5.40
  accepts a request only if its host and port are the server's own. Here,
  PHP is told it runs on `localhost`, while your browser asks for the site's
  real host, so every request would be refused. The site sets the pattern to
  `.*`, as the Docker stack's entrypoint does. Only your own tab reaches PHP,
  so a forged host has no one to mislead.
- **The first visit downloads the whole source,** about 20 MB, and unpacks it
  into the tab's memory: 7,434 files. Once the download is done, the site is
  ready in a little over a second. With the backend open beside it, the tab
  uses about 270 MB, 40 to 65 MB more than 4.0.13's, most of it the unpacked
  source. A reload restores your saved site from the browser's storage
  instead of setting it up again.
