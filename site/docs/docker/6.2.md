# TYPO3 6.2.31 with Docker

TYPO3 6.2.31, released 2017-04-18, is the last public release of the second LTS. It runs on PHP 5.6.40 and MySQL 5.5.

```sh
curl -fsSL -o typo3-6.2.yaml https://raw.githubusercontent.com/mteu/typo3-throwback/main/6.2/compose.yaml
docker compose -f typo3-6.2.yaml up -d
```

| What | Where | Credentials |
| --- | --- | --- |
| Frontend | <http://127.0.0.1:8062/> | none |
| Backend | <http://127.0.0.1:8062/typo3/> | `admin` / `password` |
| Install Tool | <http://127.0.0.1:8062/typo3/install/> | `joh316` |

Stop it and throw everything away:

```sh
docker compose -f typo3-6.2.yaml down -v
```
