# TYPO3 4.0.13 with Docker

TYPO3 4.0.13, released 2009-07-02, is the last 4.0 release. It runs on PHP 5.6.40 and MySQL 5.5.

```sh
curl -fsSL -o typo3-4.0.yaml https://raw.githubusercontent.com/mteu/typo3-throwback/main/4.0/compose.yaml
docker compose -f typo3-4.0.yaml up -d
```

| What | Where | Credentials |
| --- | --- | --- |
| Frontend | <http://127.0.0.1:8040/> | none |
| Backend | <http://127.0.0.1:8040/typo3/> | `admin` / `password` |
| Install Tool | <http://127.0.0.1:8040/typo3/install/> | `joh316` |

Stop it and throw everything away:

```sh
docker compose -f typo3-4.0.yaml down -v
```
