# TYPO3 4.5.40 with Docker

TYPO3 4.5.40, released 2015-02-19, is the last release of the first LTS. It runs on PHP 5.6.40 and MySQL 5.5.

```sh
curl -fsSL -o typo3-4.5.yaml https://raw.githubusercontent.com/mteu/typo3-throwback/main/4.5/compose.yaml
docker compose -f typo3-4.5.yaml up -d
```

| What | Where | Credentials |
| --- | --- | --- |
| Frontend | <http://127.0.0.1:8045/> | none |
| Backend | <http://127.0.0.1:8045/typo3/> | `admin` / `password` |
| Install Tool | <http://127.0.0.1:8045/typo3/install/> | `joh316` |

Stop it and throw everything away:

```sh
docker compose -f typo3-4.5.yaml down -v
```
