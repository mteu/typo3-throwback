# TYPO3 3.8.1 with Docker

TYPO3 3.8.1, released 2005-11-14, is the last release before 4.0. It runs on PHP 5.6.40 and MySQL 5.5.

```sh
curl -fsSL -o typo3-3.8.yaml https://raw.githubusercontent.com/mteu/typo3-throwback/main/3.8/compose.yaml
docker compose -f typo3-3.8.yaml up -d
```

| What | Where | Credentials |
| --- | --- | --- |
| Frontend | <http://127.0.0.1:8038/> | none |
| Backend | <http://127.0.0.1:8038/typo3/> | `admin` / `password` |
| Install Tool | <http://127.0.0.1:8038/typo3/install/> | `joh316` |

Stop it and throw everything away:

```sh
docker compose -f typo3-3.8.yaml down -v
```
